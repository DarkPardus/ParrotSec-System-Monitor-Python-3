**ParrotSec System Monitor – Python 3**

I developed a custom system monitoring application using Python 3, running on Parrot OS 7.4 with KDE Plasma.

The application provides real-time system information, including CPU usage, RAM, disk activity, network traffic, temperature sensors and running processes.

Featuring a Matrix-inspired terminal interface, live performance graphs and customizable themes.

A lightweight, practical and personalized monitoring tool for Linux enthusiasts.

**Built with Python 3 on Parrot OS.**

**ParrotSec Sistem Monitörü – Python 3**

Parrot OS 7.4 üzerinde Python 3 kullanarak kendi sistem izleme uygulamamı geliştirdim.

CPU, RAM, disk kullanımı, ağ trafiği, sıcaklık sensörleri ve çalışan işlemleri gerçek zamanlı olarak takip edebiliyor.
